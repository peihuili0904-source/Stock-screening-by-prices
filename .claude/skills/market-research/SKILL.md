# 증권사 시황·전략 리포트 일일 브리핑

## 1. 수집
```bash
python3 .claude/skills/market-research/scripts/collect.py            # 오늘(KST)
python3 .claude/skills/market-research/scripts/collect.py --date YYYY-MM-DD
```
- 로그인 정보는 환경 변수 `FNGUIDE_ID`, `FNGUIDE_PW`. 없으면 사용자에게 클라우드 환경 설정에 추가하도록 안내하고 중단한다 (채팅으로 비밀번호를 받지 않는다).
- `config.yaml` 의 카테고리 `selectors` 가 비어 있으면 스크립트는 `data/<date>/_discover/` 에 HTML·스크린샷만 남긴다. 그 스냅샷을 보고 주식시황·주식전략 목록의 `list_url` 과 selector(row/date/title/broker/analyst/link)를 채운 뒤 다시 실행한다.
- 결과: `data/<date>/manifest.json` (리포트 메타데이터) + 카테고리별 `.pdf` / `.txt`.
- 당일 리포트가 0건이면(휴일 등) 그 사실만 기록하고 끝낸다. 결과를 지어내지 않는다.

## 2. 정독
manifest 의 모든 리포트 `.txt` 를 끝까지 읽는다. 각 리포트에서 뽑을 것:
- 증권사, 애널리스트, 카테고리(시황/전략), 제목
- 핵심 주장(시장 방향성, KOSPI·KOSDAQ 밴드/목표치, 미국 증시 관련 견해)
- 근거(지표, 수급, 실적, 금리·환율·유가, 정책·이벤트)
- 추천 업종·종목, 비중 확대/축소 의견
- 리스크 요인
- 수치는 원문 그대로(단위·기간·기준 포함) 옮기고 페이지/문장 위치를 기억해 둔다.

## 3. 종합 → `reports/<date>_research-brief.md`
`references/brief-template.md` 형식을 따른다. 원칙:
- **전반적 화두**: 여러 리포트에 반복되는 주제를 언급 빈도 순으로. 각 화두에 어느 증권사가 언급했는지 표기.
- **의견 종합**: 강세/중립/약세 시각 분포, 컨센서스와 소수 의견을 구분.
- **증권사·애널리스트별 요약**: 리포트당 3~5줄. 애널리스트 의견을 과장하거나 섞지 않는다.
- **공통점·차이점**: 같은 변수(예: 금리, 환율, 반도체 업황)를 놓고 해석이 갈리는 지점을 표로 대조. 차이가 숫자라면 숫자를 나란히 적는다.
- 모든 주장 옆에 출처(증권사/애널리스트)를 붙인다. 리포트에 없는 내용은 쓰지 않고, 분석자 해석은 "정리자 코멘트"로 분리한다.
- 원문 PDF·텍스트는 커밋하지 않는다(`data/` 는 .gitignore). 요약본만 커밋한다.

## 4. 마무리
브리핑 파일을 커밋·푸시하고, 사용자에게 화두 3줄 요약과 파일 경로를 알린다.
