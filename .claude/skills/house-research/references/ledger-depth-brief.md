# 신한투자증권 리포트 재정독: 전망 장부 + 인뎁스 상세 (서브에이전트 지침)

사용자는 신한투자증권 직원이다. 이미 정리한 리포트를 다시 읽어 두 가지를 만든다. **Drive에는 아무것도 쓰지 않는다** (읽기만). 결과는 JSON 파일 하나: `<scratchpad>/depth/<그룹>.json`.

## 도구
ToolSearch `select:mcp__Google_Drive__read_file_content` 로 불러와 Drive id로 읽는다. 결과가 파일로 저장되면 Read 로 끝까지 나눠 읽는다. 대형 PDF는 Drive 텍스트가 80쪽 안팎에서 끊길 수 있다: 읽은 범위를 `coverage` 에 적는다.

## 1) 전망 장부 (모든 리포트) — 사후 검증용
리포트가 제시한 **검증 가능한 전망**을 하나도 빠짐없이 한 줄씩. 수치가 있는 전망이 핵심이다. 해당 없으면 방향 전망(상승/하락/아웃퍼폼)과 투자의견도 넣는다.
```json
{"rid":"r3","subject_type":"자산|국가|섹터|종목|매크로|금리|환율|원자재|크레딧",
 "subject":"KOSPI", "metric":"지수 수준|목표주가|투자의견|섹터 의견|금리|스프레드|EPS|영업이익|정제마진|…",
 "kind":"range|point|direction|rating",
 "low":5000, "high":8000, "point":7000, "unit":"p|%|원|달러|bp|조원|달러/배럴|배",
 "direction":"상승|하락|아웃퍼폼|언더퍼폼|유지|null",
 "horizon":"2027년 말|4Q26|1Q27|12개월|2027년 연간|…",
 "due":"2027-12-31",            // 검증 시점(기간 끝). 목표주가 12개월이면 발간일+1년
 "baseline":"5,534p (2026-10-22)", // 리포트가 밝힌 기준값(현재가·현재 금리). 없으면 null
 "statement":"원문 표현 그대로 한 문장",
 "rationale":"이 전망의 핵심 근거 한두 문장(리포트 논리)",
 "verify":"검증 방법: 어떤 데이터의 어느 날짜 값과 비교하는지 (예: KOSPI 2027-12-30 종가가 5,000–8,000p 안인지, 7,000p 대비 오차)"}
```
- 숫자는 원문 그대로(쉼표 없이 숫자 필드에, statement 에는 원문 표기). 분기 경로처럼 여러 시점이면 시점마다 한 줄.
- 종목: 투자의견·목표주가·기준 주가를 한 줄에 (`kind:"point"`, `point`=목표주가, `rating` 은 statement 에).
- 섹터 의견(비중확대 등)은 `kind:"rating"`, `due` 는 리포트가 말한 기간 끝, 없으면 발간일+6개월.

## 2) 인뎁스 상세 (본문 7쪽 이상인 리포트만)
쪽수는 텍스트의 쪽 표시나 분량으로 판단해 `pages` 에 적는다(대략이면 "약 40"). 7쪽 미만이면 `depth: null`.
```json
"depth": {
 "pages":"약 47", "coverage":"전체|1–80쪽",
 "executive_summary":["3–5개 문장"],
 "current_situation":["애널리스트가 기술한 현재 상황 4–8개: 지표·수치 포함"],
 "outlook":["앞으로의 전망 4–8개: 기간과 수치 포함"],
 "rationale":["미래 전망의 판단 근거 4–8개: 데이터·논리·비교 사례"],
 "caveats":["리스크·틀리는 조건·한계 3–6개 (리포트가 말한 것 + 읽은 범위 한계)"]
}
```
## 출력
```json
{"reports":[{"rid":"r3","title":"…","ledger":[…],"depth":{…}|null}]}
```
규칙: 리포트에 없는 숫자·의견 금지. 범위는 `–`(en dash), `~` 금지. 요약하되 숫자는 원문 그대로. 최종 응답은 짧게: 리포트별 장부 줄 수, depth 유무와 쪽수, 읽기 문제.
